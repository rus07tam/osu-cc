# osu!cc Debug Overlay

The **osu!cc Debug Overlay** is a built-in developer tool and test suite for osu!cc plugin development and UI experimentation.

## Features

- **Test Notifications**: Send simple and custom notifications to the game notification overlay.
- **Record Celebrations**: Trigger new personal best record effects directly.
- **Confirmation Dialogs**: Test in-game confirmation popups, restart dialogs, and custom prompts.
- **Card Status Previews**: Visualise all plugin states (Active, Pending Enable, Pending Disable, Pending Delete, Disabled, Failed).
- **Theme Previews**: Live preview and explore theme colours and components.

## Usage

Press the debug toolbar icon or open the debug overlay from the Plugins manager to interact with the testing tools.
