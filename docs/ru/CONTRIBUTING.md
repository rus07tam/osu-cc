# Контрибуции в osu!cc

Спасибо, что решили помочь. osu!cc это небольшой проект, поэтому хороший репорт
бага или аккуратно ограниченный PR ценятся очень высоко.

Также прочтите:

- [DEVELOPMENT.md](DEVELOPMENT.md): структура репозитория, написание плагинов, отладка
- [SECURITY.md](SECURITY.md): безопасность аккаунта и политика следа детекции
- [CODE_OF_CONDUCT.md](../../CODE_OF_CONDUCT.md)

## Что мы приветствуем

- **Репорты багов**: issues с шагами воспроизведения, ожидаемым и фактическим
  поведением и фрагментами логов.
- **Feature requests**: и PR, которые их реализуют.
- **Запросы и PR на плагины**: особенно интеграции с уже существующими
  osu!-инструментами (как `plugins/SubdivideNations`, вдохновлённый
  `osu-subdivide-nations`).
- **Расширение API**: PR, которые развивают плагин-API (`IOsuCcPluginHost`),
  чтобы плагины могли делать больше без harmony патчей.
- **PR в ядро**: всё остальное, что улучшает клиент.

## Что мы не примем

osu!cc это сознательно клиент **без читов** (см. предупреждение в README). Мы не
мержим ничего, что даёт явное преимущество, включая:

- автоматизацию геймплея (auto-play / auto-aim / relax и подобное);
- завышение, подделку или манипуляцию сабмитнутыми скорами и рангами;
- изменение того, что уходит на серверы osu!, ради преимущества (on-the-wire изменения);
- чтение или раскрытие чужих приватных данных.

Локальные изменения только своего игрового опыта это и есть смысл проекта, и
они приветствуются. Если не уверены, не пересекает ли идея черту, сначала
откройте issue и спросите, прежде чем писать код.

## Основные правила

- **Сначала обсуждение.** Открывайте issue перед большими PR, особенно теми, что
  трогают бутстраппер ядра (`osucc/Core/`) или Harmony-патчи (`osucc/Patches/`).
- **Никаких бинарей в PR.** Никогда не коммитьте сборки osu! или NuGet-блобы
  (`osu.Game.dll`, `osu.Game.Resources.dll`, `osuTK`, ...). Проприетарные сборки
  никогда не модифицируются, а NuGet-копии при деплое перезаписали бы
  продакшн-сборки.
- **Никогда не писать в каталог osu!.** Хук живёт в папке данных osu!
  (`<data>/osu-cc/hook/`), а не в каталоге установки.
- **Сборка должна оставаться чистой.** `dotnet build osucc.App/osucc.App.csproj`
  без warnings, и `dotnet format osucc.sln --verify-no-changes` должен проходить.
- **Обновлять доки.** Изменения фич сопровождаются обновлением английских и
  русских доков (README, список фич, DEVELOPMENT, где уместно).
- **Лицензия.** Контрибуции публикуются под [Unlicense](../../LICENSE) (public
  domain), как и весь проект.

## Плагины

Плагин это classlib с типом, помеченным `[OsuCcPlugin]`. Новые плагины живут в
`plugins/<Name>/` и поставляются как zip-архив с `icon.png`. Отдавайте
предпочтение host API (`IOsuCcPluginHost`) перед собственными Harmony-патчами,
где это возможно. Всё нужное есть в [DEVELOPMENT.md](DEVELOPMENT.md).

## Быстрый старт

```shell
dotnet build osucc.App/osucc.App.csproj -c Debug
dotnet osucc.App/bin/Debug/net8.0/osucc.dll start   # build + deploy + run
```

Все команды и опции лаунчера есть в [README](README.md).
