# osu!cc

**Документация:** [English](../en/README.md) · Русский · [Разработка (Ядро)](DEVELOPMENT.md) · [Разработка (Плагины)](PLUGINS.md) · [Безопасность](SECURITY.md) · [Контрибуции](CONTRIBUTING.md) · [Кодекс поведения](../../CODE_OF_CONDUCT.md)

osu!cc это дополнение к osu!lazer. Это не официальный клиент, а набор опциональных
улучшений поверх игры, которая у вас уже стоит.

Установка osu! при этом не трогается: в папку игры ничего не копируется и не
изменяется, а x-token подпись работает ровно как на оригинальном клиенте.
Единственное, что остаётся после нас, это собственная папка `osu-cc` в каталоге
данных игры, где лежат настройки, плагины и логи. Удалить клиент так же просто,
как удалить эту папку.

> **Внимание.** osu!cc это не официальный клиент osu!. Его использование
> нарушает Пользовательское соглашение osu!, и за свой аккаунт вы отвечаете сами.
> Мы не несём ответственности за всё, что с ним случится. И ещё кое-что: в этом
> проекте никогда не будет читов или чего-то подобного. Прежде чем пользоваться,
> прочтите [SECURITY.md](SECURITY.md).

## Что умеет

Большинство возможностей это тумблеры в отдельной секции **Specials**
в настройках игры.

### Основные возможности

- **Менеджер плагинов**: плагины могут добавлять кнопки на тулбар, секции
  настроек, оверлеи и свои уведомления. Плагины поддерживают lifecycle-хуки
  (срабатывают при установке, обновлении или удалении) и версионированные
  миграции данных, так что после обновлений они остаются в актуальном состоянии.
  Включение/выключение настраивается в менеджере плагинов.
- **Пропуск брейков на карте**: кнопка для пропуска пауз посреди карты во время игры, аналогично пропуску интро.
- **Несовместимые моды**: можно выбирать и играть с модами, которые обычно
  конфликтуют друг с другом.
- **Кнопка "Random mods"**: кнопка в футере мод-селектора, которая выбирает
  случайный набор валидных модов.
- **Колонка System-модов**: обычно скрытая колонка `System` (score v2, touch
  device и т.п.) появляется в мод-селекторе.
- **Новый личный рекорд**: полноэкранная анимация с частицами, когда вы
  ставите новый личный рекорд.
- **Отключение сабмита скоров**: блокирует отправку соло-скоров на серверы osu!.
  Локальные скоры сохраняются, при старте плея показывается напоминание.
- **Фейковый osu! supporter**: локальный (только для вас) тег osu!supporter с
  настраиваемым уровнем (от 1 до 10 сердечек) у текущего игрока (везде, где показывается
  профиль). На серверы ничего не отправляется. Поставляется как плагин **Fake Supporter**,
  который также добавляет переопределения для отдельных игроков и открытый API правил
  для других плагинов.
- **Подсветка избранного**: избранные карты получают розовую пульсирующую
  обводку в song select.
- **Скачать всё избранное**: кнопка в секции Beatmaps → Favourites профиля
  игрока, которая скачивает все избранные карты.
- **Брендинг**: заголовок окна становится "osu!cc".
- **Стартовый тост + дисклеймер**: уведомление о том, что клиент загрузился,
  и одноразовое предупреждение.

### Встроенные плагины

Эти плагины поставляются вместе с клиентом и отключаются в менеджере плагинов:

- **Кастомные группы пользователей**: позволяет локально создавать группы пользователей и переопределять атрибуты профилей (роли, плашки, регионы и ники на лидербордах и в карточках).
- **Градиентные ники**: красит ники игроков горизонтальным градиентом (свой ник
  и чужие, разными палитрами). Работает в таблицах скоров, чате, профилях,
  мультиплеере и на тулбаре. Свой ник также можно заменить произвольным текстом
  или скрыть за белым блоком.
- **Subdivide Nations**: показывает субнациональный регион игрока на профилях
  и карточках.
- **oii**: показывает improvement indicator рядом с общим временем игры
  в профиле игрока.
- **Friends leaderboard**: показывает дружеский лидерборд без osu!supporter,
  собирая его на клиенте из лучшего скора каждого друга на карте.
- **Debug overlay**: тестовые панели для систем уведомлений и личных рекордов.
- **ExamplePlugin**: эталонная реализация для разработчиков, демонстрирующая
  API плагинов. Если не нужен, удалите.
- **Менеджер обновлений**: держит хук и встроенные плагины в актуальном состоянии,
  не трогая установку. Он скачивает последний рантайм-бандл из GitHub releases
  или собирает его локально из официального репозитория (нужны .NET SDK и git),
  стейджит его и применяет при следующем запуске. Управляется из секции настроек,
  кнопки на тулбаре и опциональной автопроверки при старте. Удаление плагина
  не сносит хук - просто отключает автообновления.

**Менеджер обновлений** теперь рекомендованный способ обновления.


В планах:

- webview-браузер
- браузер плагинов: находить плагины и их метаданные на GitHub, устанавливать
  и включать их из менеджера плагинов.
- больше conditional-условий для цветов ника: ручные для игроков, osu!supporter,
  наличие бейджа X, друг
- шрифт ника (тоже по условиям, как цвета)
- шрифт игры
- локальные переопределения баннеров и бейджей
- кастомные баннеры и бейджи

## Как это работает

osu!lazer это .NET-приложение, поэтому osu!cc подключается через .NET startup
hook: игра выполняет наш код ещё до того, как дойдёт до `Main()`. Это раньше, чем
обычный трюк с инъекцией правилсетов, и позволяет менять то, что другие подходы
не могут. Проприетарные `osu.Game.dll`, `osu.Game.Auth.dll` и `AuthNative.dll`
никогда не изменяются.

Хук активируется только тогда, когда osu! запущен через `osucc`. Любой другой
запуск это обычный osu!.

## Установка

### Из исходников (рекомендуется)

Понадобится .NET SDK 8.0 (скачайте его с [официального сайта](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)) и установленный osu!lazer.

```shell
git clone https://github.com/rus07tam/osu-cc.git
cd osu-cc
dotnet build osucc.build.proj -t:PackBootstrapBundle -c Release
```

Это собирает хук и плагины и даёт единый рантайм-бандл
`artifacts/runtime/osucc-runtime-<версия>.zip`. Деплой — это просто распаковка
в папку данных `osu-cc` игры (внутри `hook/` и `plugins/`):

```shell
# Windows: %APPDATA%\osu\osu-cc ; Linux/macOS: ~/.local/share/osu/osu-cc
unzip artifacts/runtime/osucc-runtime-1.0.0.zip -d <данные>/osu-cc
```

Затем запустите игру с хуком:

```shell
dotnet osucc/bin/Release/net8.0/osucc.dll
```

При первом запуске вы получите и плагин **Менеджер обновлений**, который возьмёт на
себя все будущие обновления — пересоберите бандл (`dotnet build osucc.build.proj
-t:PackBootstrapBundle -c Release`) или дайте ему подтянуть свежий с GitHub
releases.

Если указываете расположение хука через `--osu-dir`, помните: это должен быть
установленный osu!, которому принадлежит папка данных. Лаунчер только читает и
никогда не пишет в установку.

### Бинарники (standalone, без сборки)

Чекаут и .NET SDK не нужны. Доступно после первого публичного релиза (`v1.0.0`).

1. Скачайте `osucc` (Linux) или `osucc.exe` (Windows) **и**
   `osucc-runtime-<версия>.zip` из последнего
   [GitHub release](https://github.com/rus07tam/osu-cc/releases); бинарник
   положите куда-нибудь в `PATH` (`chmod +x osucc` на Linux).
2. Разверните рантайм-бандл, распаковав его в папку данных `osu-cc` игры (он
   создаёт `hook/` и `plugins/`):

   ```shell
   # Windows: %APPDATA%\osu\osu-cc ; Linux/macOS: ~/.local/share/osu/osu-cc
   unzip osucc-runtime-1.0.0.zip -d <данные>/osu-cc
   ```

3. Запустите игру:

   ```shell
   osucc
   ```

Дальше за актуальностью следит встроенный **Менеджер обновлений** (пересборка локально
или подтяжка свежего релиза). Если хука ещё нет, `osucc` откажется стартовать
и укажет на релиз — лаунчер сам ничего не устанавливает.

## Команды

Голый `osucc` запускает игру (действие по умолчанию); `osucc status` показывает
состояние установки:

| Команда            | Что делает                                |
| ---                | ---                                       |
| `osucc`            | запуск osu! с развёрнутым хуком, применяя сначала отложенное обновление, если оно есть |
| `osucc status`     | показывает установку osu!, корень данных, версию хука, плагины и отложенное обновление |

Опции: `--osu-dir <путь>`, `--verbose|-v`.

Лаунчер намеренно минимален: он **ничего не собирает** и **не пишет** в
установку. Если хука нет, он завершается с ошибкой и указывает на рантайм-бандл.
Держите хук и плагины актуальными из игры через плагин **Менеджер обновлений**.
