# Code of Conduct

osu!cc is a small, community-driven project. Everyone participating (in issues,
pull requests, plugins or discussions) is expected to be respectful.

## Our standards

- Be constructive. Disagreements are fine, but keep them about the code.
- Treat others the way you'd like to be treated. The point of this project is fun
  and quality-of-life for its users.
- Harassment, discrimination and personal attacks of any kind are not tolerated.

## Enforcement

If you see a violation, report it to the maintainers (via an issue or direct
contact). Maintainers may remove comments, close issues or block contributors for
repeated or severe violations.
